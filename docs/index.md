# Welcome to Blender Asset Tracer's documentation!

![Bat, CC-BY by Megan Mitchell](_static/bat_cc_by_megan_mitchell.svg){ align=right }

Blender Asset Tracer, a.k.a. BAT🦇, can be used to list all dependencies of a
blend file, such as linked blend files, textures, Alembic files, and caches.
Furthermore, it can be used to create a [BAT Pack](packing.md), which
contains the blend file and its dependencies.

BAT started its life as the replacement of [BAM] and [blender-file].

[BAM]: https://developer.blender.org/diffusion/BAM/
[blender-file]: https://developer.blender.org/source/blender-file/
